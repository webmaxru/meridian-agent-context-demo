# Meridian approved agent skills

This folder is the fictional Meridian Platform Engineering team's trust boundary.

A skill is approved only after reviewers confirm:

1. The instructions are narrow, testable, and owned by a named team.
2. The source contains no hidden Unicode or undeclared tool access.
3. Examples do not request secrets or bypass existing controls.
4. The release is tagged; consumers pin the tag or an immutable commit.

`CODEOWNERS` protects this path in the demo repository. In production, Meridian would also require
review, signed commits or tags, and a protected release workflow.
